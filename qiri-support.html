支持

QiRi是一本离线生活小记。界面是中文，数据留在这台 iPhone 上。

四个分页

  • 今日：称呼、今天的心情、今日习惯打卡、一句引文、今天的手记
  • 习惯：添加、编辑、排序和删除习惯。打卡在「今日」
  • 手记：按月份查看，可以搜索标题或正文
  • 我的：称呼、连续记录、每天提醒、导出和恢复备份、清空记录

记下今天

  1. 第一次打开可以填写称呼，点「就这样」。也可以点「以后再说」，之后在「我的」里保存。
  2. 心情有五种。再点一次已选中的心情，会取消。
  3. 习惯右边的圆圈用来打卡。点习惯名称可以看连续天数和最近几周。
  4. 还没有手记时，今日页往下有「写一句」。已经写过时，可以打开最近一篇，或点「再写一篇」。

习惯

点右上角加号添加习惯。名称最长 20 个字。可以选颜色和图标。左上角「排序」会显示拖动手柄，排完点「完成」。左滑一行可以删除，详情页里也可以编辑或删除。删掉习惯时，它的打卡会一起删掉。

手记

标题可以留空，最长 40 个字。正文最长 8000 字。标题和正文都是空的时候不能保存。编辑已有手记时，页内有「删除这篇手记」。

提醒

在「我的」打开「每天提醒」。默认时间是 21:30，可以改。第一次打开会向系统申请通知权限。若之前拒绝了，页面上会出现「去系统设置里允许通知」。提醒只在这台手机上响，文案是「留一分钟，看看今天的习惯和心情。」

换手机

  1. 在旧手机的「我的」里点「导出备份」，把 JSON 文件存进文件 App，或用隔空投送送到新手机。
  2. 在新手机安装QiRi，点「从备份恢复」，选中那份文件，再确认替换。

备份需要是QiRi导出的当前版本文件。选错文件时，应用会说明没能读取。

清空

「清空这台手机上的记录」会回到最初的四个习惯，并删掉这台手机上的手记、心情和打卡，同时取消提醒。清空前请先导出备份。

常见情况

  • 提醒没响：确认开关已打开，系统设置允许了通知，并且没有被专注模式静音。
  • 卸载后记录没了：没有事先导出的备份，开发者无法恢复。
  • 需要网络吗：记事本身不需要。安装来源会通过 AppsFlyer 联网记录，习惯、心情和手记不会因此上传。

Support

QiRi is an offline daily notebook. The interface is Chinese. Your records stay on this iPhone.

Four tabs

  • 今日 Today: your name, today’s mood, habit check-ins, a short line, and today’s journal
  • 习惯 Habits: add, edit, reorder, and delete habits. Check-ins happen on Today
  • 手记 Journal: entries grouped by month, with search for title or text
  • 我的 Profile: name, streaks, the daily reminder, backup, restore, and clearing records

A day in the app

  1. On first launch you can enter a name and tap 就这样. 以后再说 dismisses the card. You can save a name later in Profile.
  2. There are five moods. Tap the selected mood again to clear it.
  3. The circle beside a habit checks it in. Tap the habit name for the streak and the last few weeks.
  4. With no journal yet, scroll Today and tap 写一句. After one exists, open the latest entry or tap 再写一篇.

Habits

Use the plus button to add a habit. The name can be 20 characters. Choose a color and a symbol. 排序 shows drag handles; 完成 leaves that mode. Swipe a row to delete, or edit and delete from the habit page. Deleting a habit also deletes its check-ins.

Journal

The title can be empty and is limited to 40 characters. The body is limited to 8000 characters. Save stays off while both are empty. An existing entry has 删除这篇手记 on the editing page.

Reminder

Turn on 每天提醒 in Profile. The default time is 21:30 and you can change it. The first time, iOS asks for notification permission. If it was denied, the page shows 去系统设置里允许通知. The reminder fires only on this phone and says 「留一分钟，看看今天的习惯和心情。」

Moving to a new iPhone

  1. On the old phone, open Profile and tap 导出备份. Save the JSON file to Files, or AirDrop it to the new phone.
  2. Install QiRi on the new phone, tap 从备份恢复, choose that file, and confirm the replacement.

The file needs to be a current QiRi backup. If the file cannot be read, the app says so.

Clearing records

清空这台手机上的记录 returns the four original habits and deletes journals, moods, and check-ins on this phone. It also cancels the reminder. Export a backup first if you want to keep them.

If something looks wrong

  • No reminder: the switch is on, iOS notifications are allowed, and Focus is not silencing them.
  • Records gone after deleting the app: without an exported backup, the developer cannot restore them.
  • Does it need a network: the notebook does not. AppsFlyer contacts the network to record where the install came from. Habits, moods, and notes are not uploaded.
