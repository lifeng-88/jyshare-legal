MemoGallery 是一款本地备忘录与图库工具。数据默认保存在您的设备上，不提供云同步。

常见问题

  • 备忘录数据在哪里？保存在本机应用沙盒中，卸载应用可能清除本地数据，请自行备份重要内容。
  • 图库权限：导入 / 导出图片需要系统相册权限，可在 iPhone「设置」中管理。
  • 锁定与隐藏图库：依赖面容 ID / 触控 ID 或设备密码进行验证。
  • 语言与外观：可在应用「我的」中切换中英文，以及浅色 / 深色模式。
  • 备忘录背景：可在单条备忘录或「我的 → 备忘录背景」中设置全局默认背景。

MemoGallery is a local memo and gallery app. Data stays on your device by default; there is no cloud sync.

FAQ

  • Where is my data? Stored in the app sandbox on your device. Uninstalling may erase local data—please back up important content.
  • Photos access: Import / export requires Photos permission, managed in iPhone Settings.
  • Lock & Hide Gallery: Uses Face ID / Touch ID or device passcode.
  • Language & Appearance: Switch Chinese / English and light / dark mode in Me.
  • Memo backgrounds: Set per memo, or set a global default under Me → Memo Background.
