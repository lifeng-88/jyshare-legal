QiRi

隐私政策

生效日期：2026年11月26日

QiRi是一本放在 iPhone 上的生活小记。习惯、心情和手记由你写在这台手机里。开发者没有服务器，收不到这些内容，也不做账号。

安装来源

习惯、心情和手记不上传，也没有广告或第三方登录。安装来源通过 AppsFlyer 记录：打开应用时，AppsFlyer 会收到这次安装的来源信息。系统会询问是否允许跟踪，你可以拒绝。拒绝之后，记事功能照常使用。

留在这台 iPhone 上的内容

下面这些只写在本机应用支持目录的本地文件里，用来在下次打开时还在：

  • 称呼，最多 12 个字，用来打招呼
  • 习惯的名称、图标和颜色
  • 按天记下的打卡
  • 某一天的心情：晴朗、平稳、安静、低落或沉重
  • 手记的标题和正文
  • 每天提醒是否打开，以及提醒的小时和分钟

卸载QiRi，或在「我的」里清空记录，这些内容会从这台手机上删掉。

本地提醒

只有你打开「每天提醒」，QiRi才会向系统申请通知权限。提醒由这台 iPhone 到点发出，标题是「QiRi」，正文是「留一分钟，看看今天的习惯和心情。」没有推送服务器。你可以在系统设置里关闭通知。

备份文件

导出备份会生成一个 JSON 文件，再交给系统的分享面板。文件里就是上面列出的本机内容。你把它存进文件 App、隔空投送或发给别人，是你自己的选择。从备份恢复时，QiRi只读取你选中的那个文件，并用它替换这台手机上的当前记录。开发者不会收到这份文件。

系统权限

  • 通知：仅用于每天提醒
  • 文件选择和分享：仅用于导出或恢复你自己的备份
  • 跟踪：仅用于让 AppsFlyer 了解这次安装来自哪里

QiRi不申请定位、通讯录、照片、麦克风或相机。

儿童

QiRi是个人生活记录，不面向儿童收集信息，也没有账户注册。

这份说明的更新

如果以后的版本改变了数据的去向，会更新本页，并写上新的生效日期。习惯、心情和手记仍然只留在你的 iPhone 上。安装来源会发送给 AppsFlyer。

Privacy Policy

Effective date: November 26, 2026

QiRi is a daily notebook that lives on your iPhone. Habits, moods, and journal entries stay on that phone. There is no account and no server that receives them.

Where the install came from

Habits, moods, and notes are not uploaded. There are no ads and no third-party sign-in. AppsFlyer records where the install came from: when you open the app, AppsFlyer receives that attribution. iOS asks whether tracking is allowed, and you can refuse. The notebook still works if you refuse.

What stays on this iPhone

The app writes the following into a local file in its own storage, so it is still there the next time you open it:

  • A display name of up to 12 characters, used only for the greeting
  • Habit names, symbols, and colors
  • Daily check-ins
  • One mood for a day: bright, steady, quiet, low, or heavy
  • Journal titles and text
  • Whether the daily reminder is on, and the hour and minute

Deleting QiRi, or clearing records in Profile, removes this from the phone.

Local reminders

QiRi asks for notification permission only after you turn on the daily reminder. The phone itself delivers it. The title is “QiRi” and the text is “留一分钟，看看今天的习惯和心情。” There is no push server. You can turn notifications off in iOS Settings.

Backup files

Export creates a JSON file and hands it to the system share sheet. The file contains the on-device records listed above. Saving it to Files, AirDropping it, or sending it to someone is your choice. Restore reads only the file you pick and replaces the records on this phone. The developer never receives that file.

System permissions

  • Notifications: the daily reminder only
  • File picker and share sheet: exporting or restoring your own backup
  • Tracking: so AppsFlyer can tell where this install came from

QiRi does not ask for location, contacts, photos, microphone, or camera.

Children

QiRi is a personal notebook. It does not collect information from children and has no sign-up.

Updates to this policy

If a later version changes where data goes, this page will be updated with a new effective date. Habits, moods, and notes stay on your iPhone. Install attribution is sent to AppsFlyer.
